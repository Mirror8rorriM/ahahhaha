# ДЗ №2 — два танка в Shadertoy

Задание со слайда 53 презентации «04 Кватернионы, Камеры и мат библиотеки»:
3D-сцена «земля + 2 танка», поворот башни и изменение угла орудия с клавиатуры,
выстрел снарядом по пробелу. Взрыв опциональный и в этой версии отсутствует.

Левый зелёный танк управляется игроком. Правый коричневый танк — неподвижная мишень.
Камера фиксирована. Корпуса не перемещаются, так как этого нет в задании.

## Запуск на Shadertoy

1. Откройте https://www.shadertoy.com/new.
2. Добавьте вкладку **Common** и вставьте `Common.glsl`: общие функции геометрии и кратеров.
3. Создайте **Buffer A**, вставьте `BufferA.glsl`.
4. Для **Buffer A**: **iChannel0 → Buffer A**, **iChannel1 → Keyboard**.
5. Для **Image**: вставьте `Image.glsl`, задайте **iChannel0 → Buffer A**.
6. Каналы Buffer A — **Nearest**, без mipmap. Другие каналы не нужны.
7. Обновите все три вкладки, скомпилируйте, сбросьте время, запустите воспроизведение.
   Щёлкните по изображению для фокуса клавиатуры.

Старые версии двух проходов несовместимы с новым форматом состояния: замените их целиком.
Разрешение Buffer A должно быть не меньше 68 пикселей по ширине (обычное разрешение Shadertoy подходит).

Для сохранения на сайте нужен вход в свой аккаунт. Файлы в репозитории сами по себе не публикуют шейдер на Shadertoy.

| Клавиша | Действие |
| --- | --- |
| ← / → | Поворот башни |
| ↑ / ↓ | Подъём / опускание ствола от 2° до 65° |
| Пробел | Выстрел; одновременно летит один снаряд |

Начальное наведение позволяет попасть во второй танк одним нажатием пробела.
При столкновении с землёй или корпусом/башней мишени снаряд исчезает.
Попадания оставляют объёмные кратеры и в земле, и на обоих танках — корпусе,
гусеницах, башне и стволе. Они сохраняются до сброса времени. Следующий выстрел
не удаляет прежние следы. Следы на башне и стволе поворачиваются вместе с деталью.

Хранится **до 64 кратеров суммарно**. При заполнении новые следы больше не добавляются,
старые остаются; стрельба и столкновения продолжают работать. Сброс времени очищает все следы.
Это память текущего запуска шейдера, а не сохранение после перезагрузки страницы.

Чтобы выстрелить повторно, после окончания полёта отпустите и снова нажмите пробел.
Сброс — штатной кнопкой сброса времени Shadertoy.

## Что оставлено

- Два объёмных танка: корпус, две гусеницы, башня, ствол.
- Повороты через единичные кватернионы, перспективная камера.
- Клавиатурное управление, баллистика и обнаружение попадания.
- Одноцветные материалы и простое освещение, чтобы различать поверхности.

Убраны взрыв, HUD, компас, шкала угла, индикатор готовности, камуфляж,
колёса, люк и утолщение дула, мягкие тени, туман, блики, градиент неба,
шахматная земля, управление камерой мышью, дубли WASD и отдельная клавиша сброса R.

## Объяснение и проверка

Полный разбор обоих шейдеров и проверочного скрипта: [EXPLANATION.md](EXPLANATION.md).

В подготовленной облачной среде из корня репозитория:

```bash
python3 computer-graphics-homework/hw02-tanks/verify.py
```

Для проверки нужны Python, `playwright` и Chromium (системный `chromium` либо браузер Playwright).
На Shadertoy эти зависимости не нужны. Скрипт компилирует и запускает оба прохода в WebGL 2,
проверяет управление, пределы угла, баллистику, кратеры на танке и земле,
сохранение нескольких попаданий, столкновение внутри углубления, привязку к вращению башни,
повреждения обоих танков, лимит памяти и очистку при сбросе. При ошибке возвращает ненулевой код.
`preview.png` — кадр с накопленными следами настоящих выстрелов.

Проверка в Chromium не означает публикацию или проверку в редакторе сайта Shadertoy.
