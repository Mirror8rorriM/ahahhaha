# ДЗ №2 — два танка в Shadertoy

По последнему слайду презентации «04 Кватернионы, Камеры и мат библиотеки» (слайд 53).
Выбран вариант «земля + 2 танка». Левый зелёный танк управляется игроком, правый — неподвижная мишень.

## Как запустить на shadertoy.com

1. Откройте https://www.shadertoy.com/new. Для сохранения результата понадобится вход в аккаунт.
2. Добавьте вкладку **Buffer A** через кнопку добавления прохода.
3. Вставьте содержимое `BufferA.glsl` во вкладку **Buffer A**.
4. В **Buffer A** задайте **iChannel0 → Buffer A** (обратная связь), **iChannel1 → Keyboard**. Для Buffer A используйте **Nearest**, без mipmap. Не подключайте Keyboard вместо обратной связи.
5. Во вкладке **Image** замените исходный код содержимым `Image.glsl`.
6. В **Image** задайте **iChannel0 → Buffer A**, фильтрация **Nearest**. Остальные каналы не нужны.
7. Нажмите Compile/Play. Щёлкните по изображению, чтобы клавиатура управляла шейдером.

Код не требует текстур, моделей, звука и вкладки Common. Если изображение пустое, проверьте оба подключения Buffer A и перезапустите время кнопкой сброса Shadertoy. На медленном устройстве уменьшите разрешение.

## Управление

| Клавиши | Действие |
| --- | --- |
| ← / → или A / D | Поворот башни вокруг вертикальной оси |
| ↑ / ↓ или W / S | Подъём / опускание ствола, от 2° до 65° |
| Пробел | Выстрел; одновременно летит один снаряд |
| R | Сброс башни, снаряда и взрыва |
| Зажатая левая кнопка мыши | Обзор сцены орбитальной камерой |

Начальное наведение уже позволяет попасть в правый танк: достаточно нажать пробел.
Для нового выстрела отпустите и снова нажмите пробел после попадания.
Индикатор снизу слева зелёный, когда можно стрелять, оранжевый — когда снаряд летит.
Рядом показан компас башни, справа — шкала угла возвышения.

## Соответствие заданию

- Трёхмерная сцена: земля и два объёмных танка с корпусами, гусеницами, колёсами, башнями и стволами.
- Башня и угол возвышения управляются с клавиатуры независимо от камеры.
- Пробел выпускает снаряд из дула. Снаряд движется по баллистической траектории с ускорением свободного падения.
- Попадание в землю или корпус/башню мишени создаёт анимированный взрыв. Разрушение танка заданием не требуется и не реализовано.

## Связь с презентацией

**Кватернионы, слайды 14–22.** В `axisAngle` используется единичный кватернион
`q = (axis * sin(angle/2), cos(angle/2))`. В GLSL выбран порядок `(x, y, z, w)`.
`qMul` выполняет произведение Гамильтона, `qRotate` — поворот `q * p * conjugate(q)`.
Для ствола `q = qYaw * qPitch`: сначала локальное возвышение вокруг Z, затем азимут вокруг Y.
Умножение некоммутативно. Для вычисления расстояния до повёрнутой детали точка переводится обратно в локальные координаты сопряжённым кватернионом (`toLocal`).

**Камера, слайды 29–41 и 52.** Орбитальная камера задаётся позицией и точкой наблюдения.
Из векторов forward, right и up строится ортонормированный базис `cameraToWorld`.
Лучи перспективной камеры вычисляются с вертикальным FOV 48° и поправкой на соотношение сторон.
Это обратный путь по сравнению с обычным преобразованием вершин через матрицы вида и проекции:
из пикселя экрана получается луч в мире. Никаких внешних математических библиотек в GLSL не требуется.
SLERP здесь не нужен: ориентация задаётся непосредственно клавишами.

**Отрисовка.** Использован ray marching по функциям расстояния (SDF), с освещением и мягкими тенями.
Это способ построить 3D в полноэкранном фрагментном шейдере Shadertoy без загрузки мешей.

## Состояние и физика

В нижней строке текстуры Buffer A хранятся четыре RGBA-текселя:

| Тексель | Содержимое |
| --- | --- |
| (0, 0) | Азимут, возвышение, флаг полёта, резерв |
| (1, 0) | Позиция снаряда xyz, возраст |
| (2, 0) | Скорость снаряда xyz, резерв |
| (3, 0) | Точка взрыва xyz, оставшееся время |

Состояние читается через `texelFetch`, поэтому соседние значения не смешиваются.
Keyboard: строка 0 — удержание, строка 1 — импульс нажатия. Движение использует `iTimeDelta`,
а не фиксированное перемещение за кадр. Шаг ограничен 0,05 с, чтобы возврат из фоновой вкладки не вызывал скачка;
при частоте ниже 20 FPS симуляция замедляется. Восемь подшагов проверяют столкновение снаряда радиусом 0,1
с основным корпусом и башней мишени; мелкие детали, ствол и гусеницы не входят в модель столкновений.

## Проверка

Оба прохода компилируются и выполняются в WebGL 2 (Chromium / SwiftShader).
Проверяются управление башней, ограничение угла, выстрел, движение под действием гравитации,
попадание в правый танк и создание взрыва. `preview.png` — кадр реального выполнения шейдера.
Проверка проведена локально с интерфейсом uniform-переменных Shadertoy; публикация на сайте не выполнялась.

Повторить проверку в подготовленной облачной среде:

```bash
python3 computer-graphics-homework/hw02-tanks/verify.py
```

Команда запускается из корня репозитория. Проверочный скрипт требует Python, пакет `playwright`
и Chromium (системный `chromium` либо браузер Playwright). Для самого Shadertoy Python и Playwright не нужны.
Скрипт завершается с ошибкой при сбое компиляции, проверки состояния или WebGL и обновляет `preview.png`.
